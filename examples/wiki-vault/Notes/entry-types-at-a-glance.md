## Content
Tessarios has 15 entry types. Each type comes from a template: a set of typed fields (dropdowns, dates, links to other entries) and a set of fixed sections. A type can have more than one template: Character has Hero, Antagonist and Supporting.

| Type | Use it for |
|---|---|
| Book, Chapter, Scene | the manuscript: planning and the story text |
| Character | people: heroes, antagonists, supporting characters |
| Relationship | one bond between two characters |
| Organization | clubs, families, authorities, factions |
| Place | settings at any scale |
| Power | abilities and power systems |
| Item | objects with weight in the story |
| Lore | rules, events, history, myths |
| Storyline | one thread of the plot |
| Map | images with pins, regions and floors |
| Visual | design files and prompts |
| Note | questions, research, decisions |
| Brainstorm | ideas that are not canon yet |

**Fields** live at the top of the file and are the part you tick and type. **Sections** (the `##` headings) are the prose. A field that is a link (`[[Title]]`) connects two entries.

**Create an entry:** Sidebar → *Forge New Entry*, choose the type and the template, give it a title. The new file has the template's empty fields and empty sections, nothing else.
